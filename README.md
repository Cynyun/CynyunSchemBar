# Cynyun SchemBar

Mindustry（v160 / v160.3）的 Java 悬浮窗 Mod：把蓝图（schematic）按 **栏目 → 序列 → 蓝图按钮** 三层组织起来，
常驻在游戏界面上，一键调用，不需要每次都打开原版蓝图对话框翻列表。

> 开发中。当前版本重点在 UI 与交互，功能细节见 `mod设计.md`。

## 功能

**主悬浮窗**
- 栏目行（如 S科技 / E科技 / rank）横向滚动，点一下切换当前栏目。
- 序列列（如 钻头 / 石墨 / 炮塔）横向滚动，一列一个序列，列内可单独上下滚动。
- 每个序列里是一串蓝图按钮，显示自定义标题；点按钮 = 用原版逻辑放置该蓝图。
- 鼠标悬停 0.3 秒（触摸端长按 0.5 秒）弹出详情浮层：预览图、尺寸与方块数、消耗、电力、标签、描述。
- 可拖动、拖右下角调整长宽、可收起成只显示名字的窄条；位置与尺寸会记住。

**编辑态**（标题行「编辑」）
- 栏目：新建 / 改名 / 左右移动 / 删除。
- 序列：新建 / 改名 / 左右移动 / 删除。
- 蓝图按钮：换个标题、重新选择、上移 / 下移、移除；列底「+」直接从蓝图库挑一张。
- 编辑动作直接改配置并落盘，没有「保存」按钮。

**选择蓝图窗口**
- 网格卡片展示全部蓝图，支持搜索框（忽略标点）与原版标签多选筛选。
- 可拖动、可缩放；尺寸与位置持久化。
- 一键打开原版蓝图界面，便于新建 / 编辑 / 删除蓝图。

**外观设置**
- 强调色、暗色、线条色、文字色、面板色与整体不透明度，改完即时生效。
- 恢复默认会清掉颜色与窗口位置（已绑定的蓝图不会被清掉）。

**平台适配**
- 桌面与手机各一套尺寸基准，统一收在 `src/code/theme/BarMetrics.java`，改那里就能同时调两套 UI。
- 所有尺寸随游戏的 UI 缩放（Scl）换算，不写死像素。

## 数据与存档

配置保存在：

```
%APPDATA%\Mindustry\cynyun-schembar\config.json
```

包含栏目 / 序列 / 条目结构与自定义标题、绑定关系、颜色与不透明度、各窗口位置与尺寸（桌面、手机分开存）。
删除该文件或点「恢复默认」即可回到初始状态。

## 兼容性

- 游戏版本：v160 / v160.3。
- 多人联机：`mod.hjson` 中 `hidden: true`。本 Mod 不注册任何游戏内容，因此装了 Mod 的客户端可以进原版服务器；
  反过来服务端装不装都不影响。
  代价是隐藏 Mod 不能加载内容（新方块 / 物品等），对本 Mod 没有影响。

## 构建

编译与打包不在本地跑，走 GitHub Actions：

- `.github/workflows/release.yml`：**每次 push 到 `main` 自动发布一个 release**。
  版本号由已有的 `v1.0.*` tag 推算：一个都没有时是 `v1.0.0`，之后每次把末尾数字加一
  （`v1.0.1`、`v1.0.2` …）。构建前会把该版本号写进 `mod.hjson`，所以游戏内 Mod 列表显示的版本
  与 release 一致；仓库里的 `mod.hjson` 始终保持 `1.0.0`。
- `.github/workflows/commitTest.yml`：每次提交 / PR 增量编译一次，只上传 artifact 不打 tag。

产物在 `build/libs/`（桌面 + Android 合并成一个 jar），下载 release 里的 jar 放进
`<游戏目录>/mods/` 即可。本地想编也可以直接 `gradlew deploy`，但需要 Android SDK（打包要用 `d8`）。

## 代码结构

```
src/Main.java              Mod 入口（mod.hjson 的 main）
src/code/Start.java        启动：创建窗口、挂 HUD、打开设置/选择窗
src/code/config/           配置读写（BarConfig）
src/code/theme/            颜色与尺寸基准（BarTheme、BarMetrics）
src/code/widget/           自绘基础组件（按钮、输入框、滚动条、滑条、菜单、确认框……）
src/code/window/           窗口基类（拖动、缩放、贴边吸附、位置持久化）
src/code/schematic/        蓝图相关：选择窗、卡片、详情、信息窗、槽位
src/code/color/            取色器
src/code/page/             页面：主悬浮窗、设置窗
```
